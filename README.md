An entry for [Alien Field Notes: The Two Day Earth Review](https://make.fun/c/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) on make.fun.

`main.py` writes one original line — an alien tourist's review of planet
Earth, at most 200 characters — to `/output/entry.txt`, then reads it back
and validates it against the gate (UTF-8 text, 1–200 characters, a single
line, not only white space).

Run it with:

```sh
python3 main.py
```
